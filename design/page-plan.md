# AI 知识导航 · 页面规划 (Page Plan) v2

> **配套文档**：`design-tokens.md`（设计令牌）
> **架构方向**：从单页长滚动 → 模块化分页（参考 Stripe / Linear）
> **核心目标**：主页承担"介绍 + 导航"，子页承担"功能 + 深度内容"
> **交付形式**：每页一份独立 HTML 概念稿，最终可拼接为完整站点

---

## 1. 现状与问题

| 现状 | 问题 |
|---|---|
| 单页长滚动（index.html） | 内容多时滚动疲劳，找不到入口 |
| 所有功能挤在一页 | 学习、对比、工具、AI 助手互相争抢注意力 |
| Hero 区下方直接堆内容 | 缺少"我是谁、我能给你什么"的介绍层 |
| 没有真正的"页面"概念 | 无法独立分享、SEO 单薄 |

## 3. 导航策略 (Navigation Strategy)

### 3.1 顶部导航栏（Floating Navbar · 全站共享）

```
┌─────────────────────────────────────────────────────────────┐
│ [A+] AI 知识导航    主页 学习 对比 工具 助手   [⌕] [◐] [中] [开始] │
└─────────────────────────────────────────────────────────────┘
```

- **位置**：`position: sticky; top: 0`，玻璃态背景
- **行为**：
  - 滚动方向切换：向下滚动时隐藏，向上滚动时显示（Floating Navbar 风格）
  - 当前页面在导航中高亮（`--brand-primary` 下划线 + 文字色）
- **组件**：Aceternity `Floating Navbar`
- **响应式**：`< 768px` 折叠为汉堡菜单

### 3.2 主页内导航（卡片即入口）

主页不靠顶部导航跳转，而是通过**大型 Bento Grid 卡片**作为"功能门户"：

```
┌─────────────────────────┬───────────────────┐
│                         │                   │
│   学习路径预览 (大)      │   AI 助手预览     │
│   → 跳转 /learn         │   → 跳转 /assistant│
│                         ├───────────────────┤
│                         │                   │
│                         │   模型对比预览    │
├─────────────────────────┤   → 跳转 /compare │
│                         │                   │
│   工具导航预览 (大)      ├───────────────────┤
│   → 跳转 /tools         │   关于本项目     │
│                         │   → 跳转 /about   │
└─────────────────────────┴───────────────────┘
```

- **组件**：Aceternity `Bento Grid` + `Card Spotlight`（hover 跟随光斑）
- **每张卡片**：缩略图/插图 + 标题 + 一句话 + 进入按钮（Moving Border）

### 3.3 全局搜索（⌘K Command Palette）

- **触发**：顶部 `⌕` 按钮 / `⌘K` / `Ctrl+K`
- **形式**：全屏遮罩 + 中央搜索框（Placeholders And Vanish Input）
- **搜索范围**：所有页面内容（学习节点、工具、模型、页面跳转）
- **结果**：分类展示，键盘可导航

### 3.4 路由方案（纯静态）

由于是纯静态 HTML，无路由框架，采用：

- **页面间跳转**：标准 `<a href="learn.html">`
- **当前页高亮**：每页 `<body data-page="learn">`，导航 JS 据此高亮
- **锚点跳转**：页面内 `#section-id`
- **历史记录**：浏览器原生支持
- **未来升级**：若迁移至 Next.js，可直接对应文件路由

## 4. 主页设计 (index.html)

### 4.1 目标

- 让访客 5 秒内明白"这站是干什么的、能给我什么"
- 提供清晰的"功能入口"，但不堆砌所有内容
- 用动效制造"眼前一亮"的第一印象

### 4.2 页面结构（自上而下）

| # | 区块 | 高度 | 组件 | 动效 |
|---|---|---|---|---|
| 1 | **Floating Navbar** | 64px | Floating Navbar | scroll-direction 切换 |
| 2 | **Hero** | ~600px | Grid and Dot BG + Text Generate + Placeholders Input | 文字逐字显现，搜索框占位符轮播 |
| 3 | **Stats Strip** | ~140px | 数字 + 等宽字体 | 数字 count-up 动画 |
| 4 | **Bento Grid 功能门户** | ~600px | Bento Grid + Card Spotlight | hover 跟随光斑 |
| 5 | **Roadmap 预览** | ~500px | SVG Map + Tracing Beam | 滚动时光束跟随 |
| 6 | **精选工具横滚** | ~200px | Infinite Moving Cards | 持续横滚 |
| 7 | **CTA + Footer** | ~300px | Moving Border Button + Lamp Header | 灯光效果 |

### 4.3 Hero 区详细

```
                    [v2.0 · 已更新 7 个工具]
                    
              从零开始 系统化 探索 AI 世界
                    （Text Generate 逐字）
                      
        精选学习路径 · 主流模型基准对比 · 18+ AI 工具 · 一键直达
        
        ┌─────────────────────────────────────────┐
        │ ⌕  试试搜索 DeepSeek、ChatGPT...    ⌘K │  ← Placeholders And Vanish
        └─────────────────────────────────────────┘
        
        热门 ›  DeepSeek  ChatGPT  Claude  RAG  Agent
```

- **背景**：Grid and Dot Background（双层网格 + 径向遮罩）
- **标题动效**：Text Generate Effect（JS 拆字，每字 50ms 延迟淡入）
- **"系统化"三字**：渐变文字（`--grad-hero`）
- **搜索框**：Placeholders And Vanish Input，占位符每 3s 切换（"搜索 DeepSeek" → "搜索 RAG" → ...）

### 4.4 Bento Grid 功能门户详细

采用 4 列 × 3 行的不等高布局：

```
┌──────────────┬──────┬──────┐
│              │      │      │
│   学习路径    │ AI   │ 模型 │
│   (2×2)     │ 助手  │ 对比 │
│              │(1×1) │(1×1) │
│              ├──────┼──────┤
│              │      │      │
│              │ 工具 │ 关于 │
│              │ 导航 │      │
└──────────────┴──────┴──────┘
```

每张卡片：
- 缩略插图（SVG 简笔，本站自绘，不用图片）
- 标题 + 副标题 + 一句话
- hover 时 `Card Spotlight` 跟随鼠标的径向渐变光斑
- 进入按钮 `Moving Border`（边框流光）

### 4.5 主页不包含的内容

- ❌ 完整的学习节点列表（去 `/learn`）
- ❌ 完整的模型对比表（去 `/compare`）
- ❌ 完整的工具网格（去 `/tools`）
- ❌ AI 对话界面（去 `/assistant`）

主页只放"预览"和"入口"，让访客有"想点进去看"的冲动。

## 10. 全局共享组件规范

### 10.1 Floating Navbar

- **位置**：所有页面顶部
- **内容**：Logo + 主导航 + 搜索 + 主题切换 + 语言切换 + CTA
- **当前页高亮**：`body[data-page]` → 对应导航项 `--brand-primary` 下划线
- **滚动行为**：向下隐藏，向上显示
- **响应式**：`< 768px` 折叠为汉堡菜单

### 10.2 Page Hero (小)

每个子页顶部的小型 Hero（区别于主页的大 Hero）：

```
                § 02 / Learn

              学习资源库
        从基础到前沿，12 个精选节点
```

- 高度：~280px
- 章节编号 `§ NN / Name`（等宽字体）
- 大标题 + 副标题
- 无搜索框（搜索在导航栏）

### 10.3 Footer

- **内容**：版权 + 链接（GitHub / 反馈 / 更新日志 / 回顶部）
- **样式**：顶部 1px 边框，等宽字体小字
- **全站统一**

### 10.4 主题切换

- **存储**：`localStorage` 键 `preferred-theme`
- **三态**：light / geek / dark（保留原项目三主题）
- **切换按钮**：顶部导航栏右侧，三段式
- **过渡**：所有颜色 `transition: 200ms`

### 10.5 语言切换

- **存储**：`localStorage` 键 `preferred-lang`
- **二态**：zh / en
- **实现**：复用现有 `i18n.js`，所有 `data-i18n` 属性保留

**约定**：
- 所有概念稿放在 `design/` 下，命名 `xxx-concept.html`
- 概念稿是**单文件零依赖**，双击即可在浏览器看效果
- 概念稿验证通过后，再迁移至正式页面文件
