# 快捷助手悬浮窗交付说明

> 用途：说明主页、学习区和工具区新增快捷助手入口的产品行为、实现边界、文件改动与验收结果。
> 状态：已实现，已完成本地自动化与浏览器验收。
> 日期：2026-08-02。
> 权威性：本文是本次前端改动的交付快照；如与当前代码或自动化测试冲突，以代码和测试为准。

## 1. 交付结果

本次为现有 AI 学习助手增加了一套原生快捷窗口 UI。用户无需离开当前页面，即可打开悬浮窗口继续提问、管理会话，并在需要时携带当前会话跳转到完整助手页。

快捷入口仅在以下页面挂载：

- 主页；
- 学习区；
- 工具区。

个人中心、完整助手页及其他未列入白名单的页面不会显示该入口。

## 2. 用户可见功能

### 2.1 悬浮入口与快捷窗口

- 页面右下角显示圆形对话按钮；
- 点击后在当前页面上方打开独立快捷助手窗口；
- 快捷窗口是新的原生 UI，不使用 `iframe` 引用完整助手页；
- 再次点击悬浮按钮、点击窗口关闭按钮或在适用状态下按 `Escape`，可关闭窗口；
- 打开窗口后自动将输入焦点放入对话输入框。

### 2.2 会话功能

快捷窗口复用完整助手页已有的会话、消息、登录态和生成逻辑，支持：

- 发起提问与停止生成；
- 使用欢迎页推荐问题；
- 查看长期对话与短期会话；
- 新建、打开、重命名、置顶或删除已有会话；
- 游客模式下保存和清理浏览器内会话；
- 登录用户继续使用原有服务端会话；
- 从快捷窗口跳转到完整助手页继续当前会话。

顶部操作区保持统一的按钮尺寸、圆角、悬停反馈和线性图标风格，依次提供：

1. 历史对话；
2. 快速新建对话；
3. 登录入口（仅未登录时显示）；
4. 在完整助手页中继续；
5. 关闭快捷窗口。

### 2.3 拖动与等比例缩放

- 可拖动窗口顶部非交互区域移动窗口；
- 可拖动右下角控制点缩放窗口；
- 缩放比例固定为 `7:12`，避免内容布局被任意拉伸；
- 桌面端目标宽度限制为 `340px` 至 `560px`；
- 小屏设备会按视口自动缩小，最低回退宽度为 `240px`；
- 窗口与视口边缘至少保留 `12px` 安全距离；
- 浏览器窗口尺寸变化时，快捷窗口会自动重新约束在可视区域内；
- 当前标签页会通过 `sessionStorage` 记住窗口位置、尺寸和最近会话。

## 3. 技术实现与边界

### 3.1 入口挂载

`frontend/assets/js/page-shell.js` 在通用页面壳初始化时调用 `initAssistantLauncher()`。

`frontend/assets/js/assistant-launcher.js` 通过页面的 `data-page` 值进行白名单判断，只允许：

```text
home
learn
tools
```

因此不需要在每个页面分别复制悬浮入口代码。

### 3.2 原生 UI 与逻辑复用

快捷窗口的结构和样式分别由以下文件负责：

- `frontend/assets/js/assistant-launcher.js`：窗口结构、挂载、开关、拖动、缩放和快捷操作；
- `frontend/assets/css/assistant-launcher.css`：快捷窗口完整视觉样式与响应式规则。

窗口打开时动态加载 `frontend/assets/js/assistant-page.js`。完整助手页和快捷窗口共用同一份助手前端控制逻辑，因此本次没有复制或另建：

- Agent 编排逻辑；
- Prompt 或工具调用逻辑；
- 会话 API；
- 消息流式响应逻辑；
- 用户身份、进度或学习数据逻辑；
- 后端路由、数据库表或迁移。

### 3.3 会话连续性

当前会话变化时，快捷模式通过自定义事件通知悬浮入口，并仅在会话 ID 通过安全格式校验后写入 `sessionStorage`。

跳转流程如下：

```text
快捷窗口中的当前会话
  -> 更新“在助手页中继续”的安全站内地址
  -> /assistant?session=<当前会话 ID>
  -> 完整助手页恢复同一会话
```

游客会话和登录会话均沿用既有 ID 规则。无有效会话时，跳转目标为 `/assistant`。

### 3.4 UI 对齐修复

“在助手页中继续”使用链接元素，而其他顶部操作主要使用按钮元素。为消除链接内 SVG 的行内基线偏移，所有顶部操作统一采用网格居中，并将 SVG 设置为块级渲染。

浏览器实测结果：

| 项目 | 结果 |
| --- | --- |
| 按钮中心与图标中心横向偏差 | `0px` |
| 按钮中心与图标中心纵向偏差 | `0px` |
| 悬停状态中心偏差 | `0px` |
| 跳转目标 | `/assistant` 或带当前会话参数的助手地址 |

## 7. 维护注意事项

- 不要在 `assistant-launcher.js` 内复制 Agent、会话 API 或学习业务规则；
- 助手能力发生变化时，应优先修改共享的 `assistant-page.js` 或其既有依赖；
- 新增允许显示快捷入口的页面时，应同时更新 `ALLOWED_PAGES` 和契约测试；
- 调整窗口比例时，应同步检查桌面端、窄屏端、最小尺寸和视口边界；
- 会话参数必须继续经过格式校验，并通过安全站内地址函数生成跳转链接；
- 不应把快捷窗口扩展到个人中心或完整助手页，除非产品范围明确变更；
- 不要重新改为 `iframe`，否则会产生双页面状态、身份同步和会话连续性问题。
