## 一句话结论

这是一个面向 AI 学习与工具导航的模块化单体应用：原生多页前端由 FastAPI 同源托管，Learning 和 Tools 提供公共事实，Users 拥有身份与私有状态，Agent 在这些领域服务之上执行“规则路由 → 站内检索 → 可选模型整理 → 输出守卫 → 会话/重放/观测”的受控单编排流程，SQLite 负责当前单机持久化。

Agent 的核心不是“模型自主调用任意工具”，也不是 LangGraph、多 Agent 或向量 RAG。它先由确定性服务端代码选择受控只读能力、生成引用和卡片，再允许模型基于有界站内证据改写自然语言答案；任何 Provider 异常都回退到确定性结果。唯一写能力是用户确认后的工作流保存，它通过 Users Assets 命令路径完成权限、幂等、事务与审计。

## 快速事实

| 维度 | 当前事实 |
| --- | --- |
| 架构 | 模块化单体，一个 FastAPI 部署单元 |
| 前端 | 原生 HTML/CSS/ES Modules，无 React/Vue/构建器 |
| 后端 | FastAPI 0.139.2、Starlette 1.3.1、Uvicorn 0.35.0 |
| 数据 | SQLite，无 ORM，46 张非内部表 |
| 迁移 | 当前数据库已应用 22 个迁移 |
| 公共内容 | 16 个学习节点、144 条工具事实 |
| Agent | 确定性基线 + 可选 OpenAI-compatible Provider |
| 默认模型 | `qwen3.5-flash` |
| 候选模型 | `qwen3.7-plus`，比例固定 0% |
| SSE | 同一编排结果的事件投影；适配器当前不提供真实 Provider token 级增量 |
| 会话 | 短期 30 天；长期每用户最多 3 个 |
| 运行态 | 并发、成本、重放、指标均为进程内状态 |
| 拓扑约束 | 单 worker，`process_local` |
| 生产状态 | 部署材料已准备，但仍是 NO-GO |
