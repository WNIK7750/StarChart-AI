- [ ] 从 `deploy/production/env.example` 建立部署配置；`AI_NAV_DATABASE_PATH` 与 `AI_NAV_UPLOAD_DIR` 指向源码树外持久目录，`RESET_DATABASE_ON_START=0`，生产配置预检通过。
