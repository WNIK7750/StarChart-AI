## 仍保留到最终上线的事项

以下事项继续保留在上线清单中，不通过增加当前项目体量解决：

1. 百炼默认业务空间专属域名与北京模型端点的最终配置。
2. 上海服务器真实出站 IP 白名单。
3. 供应商数据保留、训练使用和数据处理协议归档。
4. 真实 Provider 延迟、成本、配额、取消结算与结束事件验证。
5. 生产机器容量、备份恢复、监控阈值和完整浏览器矩阵。

只有单 worker 容量、滚动升级、多实例一致性或 SQLite 迁移压力出现可复现证据时，才评估共享状态 adapter；即使需要共享状态，也优先替换治理、重放和低基数指标的存储实现，不直接拆分 Agent 微服务。
