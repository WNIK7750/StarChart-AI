# 本地一键部署控制窗口设计

> 日期：2026-07-30
> 状态：本地实现与验收通过
> 范围：仓库根目录 `start.ps1` 的可重复本地部署、重启与关闭

## 1. 目标

双击或直接运行 `start.ps1` 后，在 `127.0.0.1:8088` 后台部署当前仓库版本，并让
控制窗口保持打开。窗口提供以下快捷操作：

- `R`：重新部署当前源码；
- `S`：关闭由本脚本管理的服务；
- `Q`：仅退出控制窗口，服务继续运行；
- `Enter`：刷新状态。

`-NoPause` 继续用于自动化：完成部署或确认已有受管服务后立即退出，不等待菜单。
另外提供 `-Restart` 和 `-Stop`，方便非交互调用。

## 2. 已确认根因

当前脚本在检查健康服务之前执行依赖安装；重复运行实测约 4.4 秒。它仅能确认
8088 是 AI Nav，却不记录服务归属，因此无法安全停止或重启。源码更新后再次运行只
会复用旧 Python 进程，新代码没有被重新加载。

## 3. 设计

### 3.1 仓库外运行状态

状态、日志和 requirements 指纹保存在：

```text
%LOCALAPPDATA%\AI-Nav\launcher\<仓库路径 SHA-256 前 16 位>\
```

仓库内不生成 PID、日志、数据库或临时文件。状态文件只保存：

- 规范化仓库根路径；
- 启动器创建的父进程 PID；
- 进程创建时间；
- Python 路径；
- 固定端口 `8088`。

### 3.2 进程归属

停止或重启前必须全部满足：

1. 状态文件仓库根路径与当前仓库完全相同；
2. PID 当前存在；
3. 当前进程创建时间与状态文件一致；
4. 命令行同时包含当前仓库的 Python 路径与 `backend\run.py`；
5. 进程名为 `python.exe`。

任何一项不满足都视为陈旧或外部进程：删除陈旧状态文件，但不终止进程。8088 被
不受管进程占用时明确失败，不尝试接管或强杀。

### 3.3 可重复部署

脚本先检查受管服务，再决定是否安装依赖。只有以下情况运行
`python -m pip install -r backend/requirements.txt`：

- 新建或重建了 `.venv`；
- requirements 指纹不存在；
- `backend/requirements.txt` SHA-256 发生变化。

部署使用隐藏的后台 Python 父进程，stdout/stderr 写入仓库外日志。启动后按健康
端点轮询最多 30 秒；失败时停止刚创建的受管进程并显示日志路径。

### 3.4 控制窗口

交互模式部署成功后进入循环菜单，不自动关闭。`R` 先验证归属并关闭进程树，再按
相同路径部署；`S` 关闭进程后继续保留窗口，允许按 `R` 再次启动；`Q` 只退出控制
台。意外按键只刷新菜单。

## 4. 安全与边界

- 不读取或打印 `.env`、Token、Cookie、数据库内容或 Provider 请求/响应。
- 不启用真实 Provider。
- 只允许删除精确的项目 `.venv`，且仅在其 Python 健康检查失败时。
- 不终止没有通过完整归属校验的进程。
- 不写入父目录、同级目录或 Git 追踪范围。
- 这仍是本地部署控制器，不代表 HTTP 测试服务器或生产发布。

## 5. 验收

1. 契约测试先证明菜单、仓库外状态、依赖指纹和安全归属校验缺失，再转绿。
2. PowerShell 解析零错误。
3. `-NoPause` 首次部署返回 `0`，服务健康且窗口调用方不被阻塞。
4. 第二次 `-NoPause` 快速复用，跳过依赖安装且 PID 不变。
5. `-Restart -NoPause` 返回 `0`，PID 变化且新服务健康。
6. `-Stop -NoPause` 返回 `0`，8088 不再监听。
7. 再次 `-NoPause` 可重新部署并恢复健康。
8. 未受管端口占用路径拒绝终止外部进程。
9. Node 全集、正式前端与 Foundation 门禁、`git diff --check` 全部通过。

## 6. 验收结果

- 首次受管部署、相同 PID 快速复用、PID 变化的重新部署、完整关闭以及关闭后再次
  部署均通过。
- 控制菜单 `Q` 已验证仅退出窗口；`S → R → Q` 已验证可在同一窗口关闭、重新部署
  并退出，最终服务保持健康。
- 关闭后确认 8088 无监听、状态文件已删除、当前仓库 Python 进程为 0。
- 运行状态、stdout、stderr 和 requirements 指纹只存在于 `%LOCALAPPDATA%`。
- Node 78 项、前端 62 项和完整 Foundation 门禁通过；PowerShell 解析零错误。
