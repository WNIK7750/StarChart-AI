# Clean HTTP Routes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace browser-visible product-page `.html` URLs with canonical clean routes locally and under `/StarChart-AI/`, while preserving safe legacy redirects and deployment isolation.

**Architecture:** FastAPI owns one canonical page-routing adapter before the static mount, so local 8088 and proxied 8001 behave identically. Frontend links use canonical paths, `safeInternalHref` upgrades legacy catalog URLs at the display boundary, and Nginx remains responsible only for the public prefix, proxying, caching, compression, and old-site compatibility.

**Tech Stack:** FastAPI, Starlette responses, native HTML/CSS/ES modules, Node test runner, Python unittest, Nginx, PowerShell release tooling, Playwright.

## Global Constraints

- Canonical pages are `/`, `/assistant`, `/learn`, `/learn/{slug}`, `/tools`, and `/settings`.
- Under HTTP test deployment, every canonical page is rooted below `/StarChart-AI`.
- Product pages generated by current code must not expose `.html` in browser-visible URLs.
- Known legacy `.html` pages return prefix-aware `308` redirects; safe query parameters and browser fragments remain usable.
- API, assets, uploads, deterministic Provider, account isolation, cache boundaries, and old-site routes remain unchanged.
- Do not read or print a real `.env`, account identifier, password, Token, Cookie, API key, Provider prompt, or Provider answer.
- Do not start 8002 or make a live Provider call.
- Do not merge or update `master`; work only on `agent/fix-http-subpath-navigation`.
- Build and deploy only a clean committed release whose GitHub Actions checks pass.
- HTTP test acceptance and production acceptance remain separate; production stays `NO-GO`.

```python
from __future__ import annotations

import re
from urllib.parse import urlencode

from fastapi import APIRouter, HTTPException, Request
from fastapi.responses import FileResponse, RedirectResponse

from app.core.config import FRONTEND_DIR, PUBLIC_BASE_PATH


router = APIRouter(include_in_schema=False)
SLUG_PATTERN = re.compile(r"^[a-z0-9](?:[a-z0-9-]{0,62}[a-z0-9])?$")


def canonical_location(
    path: str,
    query_items: list[tuple[str, str]] | None = None,
) -> str:
    location = f"{PUBLIC_BASE_PATH}{path}" if PUBLIC_BASE_PATH else path
    query = urlencode(query_items or [], doseq=True)
    return f"{location}?{query}" if query else location


def page(filename: str) -> FileResponse:
    return FileResponse(FRONTEND_DIR / filename, media_type="text/html")


def permanent(path: str, query_items: list[tuple[str, str]] | None = None) -> RedirectResponse:
    return RedirectResponse(canonical_location(path, query_items), status_code=308)
```

Register explicit GET/HEAD handlers for canonical pages, legacy filenames, and trailing-slash variants. The legacy learning handler removes `slug` from the retained query pairs, validates it with `SLUG_PATTERN`, and redirects invalid or missing slugs to `/learn`. The canonical `/learn/{slug}` handler raises `HTTPException(status_code=404)` for an invalid slug and otherwise returns `learn-node.html`.

- [ ] **Step 3: Implement URL canonicalization**

In `frontend/assets/js/url-safety.js`, import `PUBLIC_BASE_PATH` beside
`withPublicBasePath`, strip that validated prefix before mapping, and add:

```javascript
const LEGACY_PAGE_PATHS = new Map([
  ["/index.html", "/"],
  ["/assistant.html", "/assistant"],
  ["/learn.html", "/learn"],
  ["/tools.html", "/tools"],
  ["/settings.html", "/settings"],
]);

export function canonicalInternalPath(pathname, search = "") {
  const localPath = PUBLIC_BASE_PATH
    && (pathname === PUBLIC_BASE_PATH || pathname.startsWith(`${PUBLIC_BASE_PATH}/`))
    ? pathname.slice(PUBLIC_BASE_PATH.length) || "/"
    : pathname;
  if (localPath === "/learn-node.html") {
    const params = new URLSearchParams(search);
    const slug = params.get("slug") || "";
    params.delete("slug");
    if (/^[a-z0-9](?:[a-z0-9-]{0,62}[a-z0-9])?$/.test(slug)) {
      const query = params.toString();
      return {
        pathname: `/learn/${encodeURIComponent(slug)}`,
        search: query ? `?${query}` : "",
      };
    }
    return { pathname: "/learn", search: "" };
  }
  return {
    pathname: LEGACY_PAGE_PATHS.get(localPath) || localPath,
    search,
  };
}
```

`safeInternalHref` parses the URL, calls `canonicalInternalPath`, then passes the
canonical pathname and search through `withPublicBasePath`.

Replace current frontend-generated page URLs with canonical root-relative paths.
For direct navigation assignments, always call `safeInternalHref` so the
`/StarChart-AI` prefix is retained.
